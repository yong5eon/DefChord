# Application 훅 변경 로그

## 구현 내용

- Application 시작, 정리, 요청, 응답, 오류 훅과 공개 인터페이스를 추가했다.
- 훅 입력으로 단일 인스턴스 또는 인터페이스 시퀀스를 지원하고, 잘못된 입력은 명시적으로 거부한다.
- Extension의 정리 순서를 역순으로 유지하고, 정리 오류가 발생해도 남은 정리를 시도한 뒤 첫 오류를 전파하도록 했다.
- 요청 처리 훅의 실행 순서, 오류 전달, 직접 출력 응답 계약 및 동기 재진입 차단을 구현했다.
- 샘플에 다섯 Application 훅의 로그 예제를 추가했다.

## 서버 시작 로그 순서 수정

- Python 및 Uvicorn 어댑터에서 서버 시작 안내를 출력한 뒤 Application을 시작하도록 순서를 변경했다.
- Application 시작 훅 로그가 서버 배너보다 먼저 출력되던 문제를 수정했다.
- 샘플 로그는 `Sample` 로거를 사용하고 INFO 수준으로 stdout에 출력하도록 설정했다.

## 검증

- 전체 테스트 **153개 통과, 5개 건너뜀**.
- 수정한 Python 파일의 `py_compile` 검사 및 `git diff --check` 통과.
- 샘플 실행 시 `Starting` 안내가 `INFO:Sample:Application started`보다 먼저 출력되는 것을 확인했다.
