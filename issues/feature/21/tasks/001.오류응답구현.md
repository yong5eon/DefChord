## 확인 및 변경

- 기존 세 오류 훅은 `None`만 반환하며 오류를 다시 전파하는 것을 확인했다. HTTP adapter에는 미처리 예외를 응답으로 바꾸는 기존 fallback이 있었다.
- 세 오류 훅 반환 타입을 `Optional[Response]`로 확장하고, `None` 후속 진행·최초 `Response` 채택·계층별 전파·writer 시작 후 교체 금지를 구현했다.
- Application 응답 훅에서 오류가 발생하는 경우 응답 본문을 정리하고 Application 오류 응답으로 복구할 수 있도록 했다.
- 계층별 회귀 테스트를 추가하고 오류 처리 한국어·영어 매뉴얼을 작성했다. 생명주기 매뉴얼의 파일명을 `Lifecycle`로 분리하고 관련 링크를 갱신했다.
- 구현 파일과 테스트는 [IMPLEMENTS.md](../IMPLEMENTS.md)에 정리했다.

- 테스트 import가 실패한 최초 시도는 저장소가 editable 설치되지 않았고 `tests`가 모듈 패키지가 아닌 실행 형태를 사용했기 때문이다. 저장소 안내에 따라 `python -m pip install -e .`로 설치한 후 저장소 루트에서 `unittest discover`를 사용했다.

  - `python -m unittest discover -s tests -p 'test_writers.py'`: 19개 통과
