# 주석 API 미구현 확인

- 주석 인코딩·일반/chunked 전송·오류·상태에 대한 테스트 4개와 기존 직접 출력 통합 테스트의 주석 확인을 추가했다.
- 저장소 루트의 `tests`를 실행 위치로 다음 명령을 실행했다.

```shell
python -m unittest test_writers.WriterTests.test_sse_comment_encoding_and_transports test_writers.WriterTests.test_sse_comment_between_events_preserves_fields test_writers.WriterTests.test_sse_comment_requires_open_response test_writers.WriterTests.test_sse_comment_propagates_write_and_flush_failures
```

- 결과: 테스트 4개 실행, 하위 사례 38개가 `ServerSentEventsWriter`에 `comment`가 없다는 `AttributeError`로 실패했다. 환경 오류가 아니라 추가할 API의 미구현 상태를 확인했다.
- Pylance로 수정한 테스트 파일의 구문 오류가 없음을 확인했다.
- 다음 단계는 주석 메서드 구현과 동일 테스트 재실행이다.
