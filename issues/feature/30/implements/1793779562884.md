# SSE 주석 전송 API 구현

- [ServerSentEventsWriter.comment](../../../../src/IO/Writers/ServerSentEventsWriter.py)에 필수 문자열 인자를 받는 동기 API를 추가했다.
- CRLF·CR을 LF로 정규화하고 LF로 나눈 모든 줄 앞에 `: `를 붙여 마지막 빈 줄과 함께 UTF-8로 인코딩한다. 빈 입력과 중간·마지막 빈 줄도 보존한다.
- 기존 `self.writer.write()` 성공 후 `self.writer.flush()`를 호출한다. 일반·chunked 출력, 상태 검사와 오류 전파를 하위 writer에 맡겨 기존 응답 생명주기와 이벤트 API는 변경하지 않았다.
- [신규 테스트의 미구현 확인](../tasks/1793779513087.md) 이후 구현했으며 회귀 검증은 [별도 작업 기록](../tasks/1793779562885.md)에 정리했다.
- 한국어·영어 상세 매뉴얼에 주석 사용 예시와 자동 heartbeat 미제공·flush 보장 범위를 반영한다. 매뉴얼 정리와 최종 인수 검토는 이어서 수행한다.
