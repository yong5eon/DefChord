# Specifications OpenAPI YAML 응답 형식 추가

## 변경 내용

- `Specifications`에 `document_format`/`yaml_media_type` 옵션을 추가해 JSON 기본 동작을 유지하면서 YAML 응답을 선택할 수 있도록 변경했습니다.
- YAML 직렬화는 `PyYAML` 선택 의존성으로 처리하고, 의존성 누락/직렬화 실패 시 조용한 폴백 없이 오류를 전파합니다.
- JSON과 YAML 출력의 의미 동등성, 비ASCII·오인 가능 문자열 보존, 오류 처리 경로를 테스트로 검증했습니다.
- 한/영 상세 매뉴얼에 형식 선택 방법, YAML 미디어 타입, 설치 조건을 반영했습니다.
