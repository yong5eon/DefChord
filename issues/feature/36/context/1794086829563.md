# 이슈 36 요구사항 분석 및 설계 근거

- 이슈 요구사항을 기준으로 형식 선택 정책을 확정했다. 요청 단위 협상 대신 확장 생성 시점 설정(`document_format`)을 공개 API로 채택해 기본 JSON 호환성을 유지하고 동작을 명시적으로 고정한다.
- YAML 직렬화는 표준 라이브러리 부재를 고려해 선택 의존성 `PyYAML`을 런타임 로딩하도록 결정했다. 미설치 시 예외를 숨기지 않고 실패시켜 설치 누락을 즉시 알린다.
- OpenAPI 3.2는 직렬화 포맷 확장과 별개로 범위를 분리했다. 이번 이슈에서는 3.1 생성 로직을 유지하고, 3.2는 도구 호환성과 생성 필드 검토 후 별도 과제로 남긴다.
