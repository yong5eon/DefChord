# 모든 PR 에 대해서 테스트를 진행 할 수 있도록 워크플로 변경

## 작업 목적

master 의 브랜치에 대해서만 PR, PUSH 시 테스트가 동작
테스트는 모든 PR 과, master 의 PUSH 에 대해서만 동작 해야함

## 작업 내용 및 대상

깃헙 워크플로

- 모든 브랜치에 대해서 PR 생성 시 테스트 
- master 브랜치에 대해서 PUSH 시 테스트
- 릴리즈 관련 작업은 master 에 대해서만 진행

## 완료 기준

- 모든 브랜치에 대해서 PR 생성 시 테스트 
- master 브랜치에 대해서 PUSH 시 테스트
- 릴리즈 관련 작업은 master 에 대해서만 진행
