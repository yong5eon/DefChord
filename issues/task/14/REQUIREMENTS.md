# DefChord 문서 현지화 및 Python 설명 문구 영어화 요구사항

## 목적

DefChord 사용자 문서를 한국어와 영어로 제공하고, 프로젝트의 관리 대상 Python 파일에서 독스트링, 주석, 사용자에게 노출되는 예외 메시지를 영어로 통일한다. PyPI에는 별도의 영어 설명 문서를 게시해 패키지 소개가 영어로 표시되도록 한다.

## 범위

### 대상

- `README.md`: 저장소의 한국어 사용자 매뉴얼
- `README.en.md`: 저장소의 영어 사용자 매뉴얼
- `README.setup.md`: PyPI 패키지 설명에 사용하는 영어 문서
- `setup.py`: PyPI 설명 문서의 경로를 지정하는 패키지 설정
- Python 문구 변경 대상:
  - `src/`, `samples/`, `tests/` 아래의 Python 파일
  - 프로젝트 루트의 `setup.py`

### 제외

- 공개 API, 식별자, 예외 유형, 제어 흐름, 데이터 형식 및 런타임 동작 변경
- 독스트링·주석·예외 메시지 외의 사용자 인터페이스, 로그, 프로토콜 값, 테스트 입력 데이터 번역
- 명시된 대상 경로 밖의 프로젝트와 Python 파일 변경

## 기능 요구사항

### DOC-01: 한국어 사용자 매뉴얼

- `README.md`는 한국어로 작성한다.
- 설치 방법, 빠른 시작, 주요 기능과 사용 방법을 포함한다.
- 실제 프로젝트의 공개 기능 및 사용 방법과 일치해야 한다.

### DOC-02: 영어 사용자 매뉴얼

- `README.en.md`를 새로 작성한다.
- `README.md`와 같은 주요 주제와 기능 범위를 다루는 영어 문서로 제공한다.
- 설명과 예제가 실제 프로젝트의 API 및 동작과 일치해야 한다.

### DOC-03: PyPI 패키지 설명

- `README.setup.md`를 PyPI 패키지 페이지에 적합한 영어 문서로 새로 작성한다.
- 프로젝트 소개, 설치 방법, 빠른 시작을 포함한다.
- 문서에 외부 URL 또는 외부 웹 페이지로 연결되는 링크를 포함하지 않는다. 링크 형태의 외부 참조뿐 아니라 일반 텍스트로 표기한 외부 URL도 금지한다.
- PyPI에서 독립적으로 표시되어도 목적과 설치·시작 방법을 이해할 수 있도록 작성한다.

### PKG-01: PyPI 설명 문서 연결

- `setup.py`의 `long_description`은 `README.setup.md` 내용을 읽어야 한다.
- `long_description_content_type`은 마크다운 형식을 유지한다.
- 패키지를 빌드했을 때 메타데이터의 설명 본문에 `README.setup.md` 내용이 포함되어야 한다.

### PY-01: 독스트링과 주석

- 범위에 포함된 Python 파일에서 한국어로 작성된 독스트링과 주석을 영어로 작성한다.
- 문맥에 맞는 자연스러운 영어로 번역하되, 문서화 대상의 의미와 제약을 보존한다.
- 기존에 이미 영어인 문구는 불필요하게 다시 작성하지 않는다.

### PY-02: 예외 메시지

- 범위에 포함된 Python 파일의 `raise` 문에서 사용자에게 노출되는 예외 메시지를 영어로 작성한다.
- 메시지의 의미, 오류 상황, 사용자에게 필요한 조치 정보가 있다면 이를 보존한다.
- 예외 유형, 발생 조건, 예외 체인 및 처리 동작은 변경하지 않는다.
- 메시지가 테스트에서 검증되는 경우 기대 문자열도 새 메시지에 맞춰 갱신한다.

## 제약 및 호환성

- 변경은 문서 및 지정한 설명 문구에 한정한다.
- 공개 API, 함수 인자와 반환값, 예외 유형, 프로토콜 계약, 실행 결과는 기존과 동일해야 한다.
- 한국어가 포함된 테스트 데이터, 입력값, 임의의 사용자 콘텐츠는 번역 대상이 아니다. 검색 결과만을 기준으로 일괄 치환하지 않는다.
- `README.setup.md`의 외부 링크 금지는 이 문서에만 적용한다. `README.md`와 `README.en.md`의 링크 정책은 이 요구사항에서 변경하지 않는다.
