# DefChord 문서 현지화

이전에는 저장소에서 한국어 사용자 안내가 제한적이었고, PyPI 패키지 설명은 저장소 README를 그대로 사용했습니다. 이제 한국어 매뉴얼과 이에 대응하는 영어 매뉴얼을 제공하며, 패키지 설치 페이지에는 별도의 간결한 영어 안내가 표시됩니다.

Python 코드 설명도 영어로 통일했습니다. 공개 API와 애플리케이션의 실행 동작은 변경되지 않았으므로 기존 코드를 수정하거나 마이그레이션할 필요가 없습니다.

설치와 빠른 시작은 PyPI 설명에서 바로 확인할 수 있습니다. 저장소의 전체 사용 안내는 한국어 [사용자 매뉴얼](../../../README.md)과 [영어 매뉴얼](../../../README.en.md)을 참고하세요.
