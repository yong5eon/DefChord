# DefChord 문서 현지화 및 Python 설명 문구 영어화

## 작업 목적

공개 프로젝트의 사용자 문서를 한국어와 영어로 제공하고, 배포되는 Python 코드의 설명 및 예외 문구를 영어로 통일한다. 문서와 문구의 언어만 변경하며 기존 API와 실행 동작은 유지한다.

## 작업 범위

### 문서

- `README.md`: 설치, 빠른 시작, 주요 기능과 사용 방법을 포함하는 한국어 사용자 매뉴얼로 작성한다.
- `README.en.md`: `README.md`와 같은 범위와 구조를 갖는 영어 매뉴얼을 새로 작성한다.
- `README.setup.md`: PyPI 패키지 설명에 사용할 영어 문서를 새로 작성한다. PyPI 사용자에게 필요한 프로젝트 소개, 설치 방법, 빠른 시작을 포함하며 외부 링크를 넣지 않는다.
- `setup.py`: 패키지 메타데이터의 `long_description`이 `README.setup.md`를 읽도록 변경한다. PyPI 설명에 한국어 문서가 노출되지 않아야 한다.

### Python 문구

- 대상은 DefChord 프로젝트의 관리 대상 Python 파일이다: `src/`, `samples/`, `tests/` 아래의 `.py` 파일과 루트 `setup.py`.
- 대상 파일의 독스트링, 주석, `raise` 문에서 사용자에게 노출되는 예외 메시지를 자연스러운 영어로 작성한다.
- 식별자, API 이름, 예외 유형, 조건 및 처리 로직은 변경하지 않는다. 번역에 수반되는 메시지 문자열 변경 외의 동작 변경은 이 작업 범위에 포함하지 않는다.

## 완료 기준

- `README.md`는 한국어 매뉴얼이며, `README.en.md`는 이에 대응하는 영어 매뉴얼이다.
- `README.setup.md`는 영어로 작성되고, `setup.py`가 이 문서를 패키지의 PyPI 설명으로 사용한다.
- `README.setup.md`에는 외부 URL 또는 외부 페이지로 연결되는 링크가 없다.
- 지정한 Python 파일의 독스트링과 주석에 한국어 설명 문구가 남아 있지 않다.
- `raise` 문에서 사용자에게 노출되는 예외 메시지가 영어이며, 메시지 변경으로 영향을 받는 테스트도 갱신되어 통과한다.
- 변경은 문서와 설명 문구에 한정되고, 공개 API와 기존 실행 동작이 유지된다.
- Python 파일의 한글 검색 결과를 검토하여 남은 한글이 있다면 대상 범위의 문구인지 확인한다. 테스트 데이터 등 번역 대상이 아닌 문자열은 불필요하게 변경하지 않는다.
