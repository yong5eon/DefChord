# DefChord 문서 현지화 및 Python 설명 문구 영어화 작업 계획

## 목표

[요구사항 명세서](./REQUIREMENTS.md)에 따라 사용자 문서와 Python 설명 문구를 현지화하고, PyPI 패키지 설명이 독립적인 영어 문서로 제공되도록 한다. 기존 공개 API와 실행 동작은 유지한다.

## 작업 단계

1. **현행 문서와 기능 확인**
   - `README.md`, 샘플, 공개 API 및 패키지 설정을 확인해 현재 사용법과 공개 기능을 정리한다.
   - 기존 `README.md`가 한국어 매뉴얼 요구사항을 충족하는지 검토하고, 누락된 설치·빠른 시작·기능 설명을 식별한다.
2. **사용자 문서 작성**
   - `README.md`를 요구사항에 맞는 한국어 매뉴얼로 정리한다.
   - `README.en.md`를 작성하고 한국어 매뉴얼과 주요 주제 및 기능 범위를 맞춘다.
   - PyPI에서 독립적으로 읽을 수 있는 `README.setup.md`를 영어로 작성한다. 외부 링크와 일반 텍스트 URL이 포함되지 않도록 확인한다.
3. **PyPI 설명 연결**
   - `setup.py`가 `README.setup.md`를 `long_description` 원본으로 읽도록 변경한다.
   - 마크다운 콘텐츠 형식 및 패키지 메타데이터에 설명 본문이 포함되는지 확인한다.
4. **Python 문구 조사 및 번역**
   - 대상 Python 파일에서 한글이 포함된 독스트링, 주석, `raise` 예외 메시지를 분류한다.
   - 테스트 데이터, 사용자 입력 예시 등 번역 제외 항목은 보존하고, 해당 문구만 의미를 유지해 영어로 바꾼다.
   - 번역된 예외 메시지를 검증하는 테스트가 있다면 새 메시지에 맞춰 기대값을 갱신한다.
5. **검증 및 회귀 확인**
   - 대상 Python 파일의 한글 검색 결과를 검토해 남은 항목이 요구사항의 제외 범위에 해당하는지 확인한다.
   - `README.setup.md`의 URL 및 링크를 검사하고, 패키지 메타데이터가 이 문서를 사용하고 있는지 확인한다.
   - 관련 테스트를 실행하고 공개 API, 예외 유형, 프로토콜 계약 및 런타임 동작에 변경이 없는지 확인한다.

## 검증 기준

- `README.md`는 한국어, `README.en.md`와 `README.setup.md`는 영어로 작성되어 있다.
- 두 사용자 매뉴얼은 주요 주제와 기능 범위가 대응하며, 문서의 설명과 예제가 실제 구현과 일치한다.
- `README.setup.md`에 외부 URL이나 외부 페이지 링크가 없고, PyPI 설명 본문으로 사용된다.
- 대상 Python 파일의 독스트링과 주석에 한국어 설명 문구가 남아 있지 않다. 발견된 잔여 한글은 번역 제외 대상임을 확인한다.
- 대상 Python 파일의 사용자 노출 예외 메시지가 영어이며, 관련 테스트가 갱신되어 통과한다.
- 관련 테스트가 통과하고, 변경 범위 밖의 API와 런타임 동작에 회귀가 없다.
