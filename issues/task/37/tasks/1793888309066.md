# 이슈·브랜치·지침 및 CI 확인

GitHub 이슈 [#37](https://github.com/yong5eon/DefChord/issues/37)을 생성하고 `task` 레이블 적용을 재조회해 확인했다. 로컬 경로의 remote URL은 `yong5eon/DefEssential`이지만 GitHub canonical 저장소가 `yong5eon/DefChord`이며 이슈가 그 주소로 연결되는 것을 확인했다. 작업 트리가 깨끗하고 현재 브랜치가 `master`인 것을 확인한 뒤 `task/37`을 만들었다.

프로젝트별 지침이 Git에서 추적되는 `instructions/`에 있고, 공통 원본이 `yong5eon/Instructions`임을 확인했다. `.github/workflows/ci.yml`의 릴리즈 노트 단계가 PR head branch에서 `issues/{branch}/CHANGELOG.md`를 읽는 것을 확인했다. 따라서 `task/37`에 대응하는 필수 경로는 `issues/task/37/CHANGELOG.md`다. 이슈 설명의 폴더 표기도 Git에서 추적되는 소문자 `instructions/`로 정정했다.
