# 변경 로그

- 설치, 라우트, 요청 검증, 응답·스트리밍, 확장과 서버 실행을 설명하는 한국어·영어 상세 매뉴얼을 제공하고, 프로젝트 README에서 핵심 시작 정보를 찾기 쉽게 정리했습니다.
- 패키지 설치 화면에서 바로 확인할 수 있도록 독립적인 영어 소개와 최소 실행 예제를 구성했습니다.
- 매뉴얼을 주제별 안내로 나누고, 진입 문서에 프레임워크 소개와 요청 처리 구조 및 학습 경로를 추가했습니다.
- 인증과 Origin/CORS 정책을 별도 절로 설명하고, 설정 예제와 자격 증명·preflight 처리, 보안상 주의사항을 보강했습니다.
- 요청 처리 다이어그램에 응답 훅과 응답 전송 순서를 추가하고, 제공되는 인증 자격 증명 추출기와 OAuth2 보안 스키마를 모두 정리했습니다.
- 일반 라우트·요청·응답 내용을 하나의 안내로 연결하고, 네 가지 스트리밍 입력·출력 방식과 SSE·WebSocket을 별도 매뉴얼로 통합했습니다.
- 기본 응답, JSON, 텍스트, 파일 응답의 선택 기준과 텍스트 응답 예제를 추가했습니다.
- 매뉴얼 제목과 목차를 라우트·요청·응답 범위에 맞게 통일했습니다.
- 생명주기 매뉴얼에 요청 ID를 응답 헤더로 전달하는 응답 훅 예제를 추가했습니다.
