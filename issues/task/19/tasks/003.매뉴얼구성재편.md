# 일반 요청·응답과 스트리밍 문서 재구성

## 작업 정보

- 작업 일시: 2026-10-25
- 목적: 일반 HTTP 요청·응답을 하나의 학습 흐름으로 구성하고 스트리밍 통신을 별도 안내로 분리
- 관련 이슈: DefChord #19

## 확인 및 수행 내용

- 사용자 선택에 따라 일반 라우트·요청·응답을 한 문서에서 다루고, 네 가지 스트리밍 입출력 방식과 SSE·WebSocket을 별도 문서 쌍으로 묶었다.
- 기존 `ResponsesAndStreaming`의 JSON·텍스트·파일 응답 설명을 `RoutingAndRequests`로 이동했다.
- `StreamingAndWebSockets` 및 `.en.md`를 작성해 Content-Length 입력, chunked 입력, 일반/청크 출력, SSE, WebSocket 예제와 동작을 설명했다.
- WebSocket 안내를 새 스트리밍 문서로 통합하고, 기존 분리 문서 4개를 제거했다.
- 매뉴얼 인덱스와 Getting Started 링크, 이슈 요구사항·계획·구현 기록·변경 로그를 새 구성을 반영해 갱신했다.

## 검증

- 한국어·영어 문서의 Markdown 구조와 내부 링크 검증
- Python 코드 블록 구문 검사
- 일반·chunked 입력 리더와 일반·chunked 출력 writer 및 SSE 예제의 런타임 동작 확인
- 기존 문서 파일을 가리키는 링크가 남지 않았는지 검사
- `git diff --check`

## 상태

- 완료. 두 입력 스트림과 세 출력 방식(일반, chunked, SSE)의 예제를 실제 실행해 동작을 확인했다. WebSocket 예제는 구문과 공개 API 시그니처를 확인했으며, server adapter를 통한 연결 통합 실행은 수행하지 않았다.
