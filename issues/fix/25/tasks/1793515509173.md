# Python 3.9 CI runner 고정

사용자 요청에 따라 DefStream의 `.github/workflows/ci.yml`을 기준으로 `test.runs-on`을 `${{ matrix.os || 'ubuntu-latest' }}`로 바꾸고 Python 3.9에만 `os: ubuntu-24.04`를 추가했다. Python 3.10부터 지원하는 DefPixel은 사용자 확인에 따라 변경하지 않았다.

PyYAML로 변경 전·후 YAML을 파싱하고 DefStream과 동일한 runner 표현식·매트릭스인지 확인했다. 6개 Python 조합을 전개하여 3.9는 `ubuntu-24.04`, 3.10~3.14는 `ubuntu-latest`인 것을 확인했다. 두 변경을 제외한 전체 워크플로의 의미와 Pixel 작업 트리가 그대로임을 검증했다. `git diff --check`도 통과했다.

최초 검증은 로컬 cp949 디코딩 오류로 중단되어 `PYTHONUTF8=1`로 재실행했다. 실제 GitHub runner 실행·커밋·푸시는 수행하지 않았다. 고객 기능·설치 계약은 변경하지 않아 사용자 매뉴얼과 고객용 변경 로그는 수정하지 않았다.
