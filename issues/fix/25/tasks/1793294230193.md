# 이슈와 패키징 계약 확인

원본 #25의 `fix` 레이블과 댓글 부재를 확인하고 본문을 README에 보존했다. 사용자 확인에 따라 `master`에서 `fix/25`를 생성했다. 시작 시 작업 트리는 깨끗했다.

`find_packages('src')`가 두 선택 어댑터를 모두 포함함을 확인했다. 코어가 공통 부모와 Python 서버를 소유하고 구현체 배포물이 각 하위 경로만 소유하는 방향으로 요구사항과 계획을 작성했다.

빌드 도구가 없는 환경을 확인한 뒤 저장소 밖 Python 3.13 가상환경에 build, setuptools, setuptools-scm, wheel, twine과 YAML 검증 도구를 설치했다. setuptools 명령 확장 시그니처를 실제 구현과 대조했다. 다음 단계는 대상별 배포 구현이다.
