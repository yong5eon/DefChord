# 배포 조합과 기존 동작 검증

Python 3.13에서 `python scripts/build_distributions.py --no-isolation`로 같은 검증 버전의 코어·Gunicorn·Uvicorn wheel/sdist를 생성했다. 검증 버전은 환경변수로만 지정했고 제품 버전을 코드에 고정하지 않았다.

`python scripts/check_distributions.py --editable` 검사에서 다음을 확인했다.

- 세 wheel의 파일 소유권이 중복되지 않음
- 각 sdist를 빌드 대상 환경변수 없이 독립 wheel로 재빌드했을 때 이름·버전·제품 파일 내용 유지
- 기본·각 단일 extra·전체 extra의 네 설치 조합에서 선택하지 않은 구현체 부재와 선택한 구현체 import
- 추가 extra 설치, 동일 버전 재설치 및 한 구현체 제거 후 나머지 유지
- 코어 strict editable과 구현체 전용 finder 조합의 격리 및 코어 소스 변경 반영

설치한 배포물에 대해 저장소 밖에서 `tests/`를 입력으로 unittest discovery를 실행해 253개를 수행했고 통과했다(5개 건너뜀). `scripts/`의 릴리즈 준비 단위 테스트 6개도 통과했다. 실제 PyPI 접근·게시 대신 HTTP 응답을 모킹하여 새 릴리즈, 기존 파일 재사용·불일치, 누락 배포물과 빌드 번호 오류를 검사했다.

잘못된 `DEF_BUILD_TARGET` 값이 오류로 종료됨을 확인했다. YAML·내장 Python 구문, 변경 Markdown의 구조·상대 링크·개인 경로 검사도 통과했다. 최소 지원 Python 및 추가 editable 동작·이전 통합 버전 전환 검증을 이어간다.
