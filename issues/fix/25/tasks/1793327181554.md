# 리뷰 지적의 재현과 수정 검증

공통 helper의 문제는 DefStream의 같은 코드에 신규 테스트를 먼저 추가하여 3건 모두 실패하는 것으로 재현했다. 수정 후 Python 3.9 패키징 단위 테스트 22개, Linux Python 3.9 링크 테스트 10개와 helper·테스트의 Pyright 검사를 통과했다.

저장소 루트에서 실행한 주요 검증:

```shell
python -m unittest discover -s scripts/tests -t scripts -p "test_*.py"
python -m pyright scripts/editable_view.py scripts/tests/test_editable_view.py
```

전용 Python 3.9 검증 환경에서 한영 GettingStarted의 `python -m pip install -e . --config-settings EXTRAS=Gunicorn,Uvicorn`과 `python -m unittest discover -s tests`를 실행하여 전체 253개 통과(5개 건너뜀)를 확인했다. 최초 실행은 환경의 pip 22.0.4가 `--config-settings`를 지원하지 않아 실패했으며 pip 26.0.1로 갱신 후 통과했다. 공유 개발 환경은 변경하지 않았다.

Python 3.9에서 `python scripts/check_distributions.py --dist-dir dist/inline-manifest --editable`을 통과했다. 기존 일반 배포 산출물의 소유권·sdist 재빌드·네 설치 조합·설치 수명주기를 확인하고, 현재 수정된 helper를 복사한 로컬 소스로 editable 선택 교체·해제·로컬 버전 갱신·새 파일 반영·두 환경 격리를 검증했다. 이번 검증을 새 일반 배포 산출물의 재빌드로 보고하지 않는다.

세 프로젝트 helper와 링크 테스트의 SHA256이 각각 동일하다. Pylance 구문 검사도 동일한 DefStream 파일에서 오류가 없었다. 한영 매뉴얼·변경 로그의 계약을 대조했다. 이전 PR의 원격 CI 통과는 확인했으나 이번 미커밋 수정의 원격 CI는 실행하지 않았다. 커밋·푸시·리뷰 해결 처리·병합·배포는 수행하지 않았다.
