# editable 링크의 차등 갱신과 전체 테스트 안내 정정

[링크 갱신 리뷰](https://github.com/yong5eon/DefEssential/pull/26#discussion_r4417348050)와 [테스트 안내 리뷰](https://github.com/yong5eon/DefEssential/pull/26#discussion_r4417348128)를 반영했다.

- `scripts/editable_view.py`의 `refresh()`에서 전체 삭제·재생성을 제거했다. 같은 원본을 가리키는 링크는 유지하고 변경된 파일은 같은 부모의 임시 디렉터리에 새 링크를 만든 뒤 `Path.replace()`로 교체한다. 링크 생성 실패 시 해당 기존 파일과 선택 기록을 유지하며 오류는 전파한다.
- 이전 선택에서 빠진 관리 파일만 제거한다. 영향을 받은 파일의 bytecode만 지우고 빈 디렉터리를 정리한다. 미관리 파일로 비어 있지 않은 디렉터리는 보존하며 그 외 삭제 오류는 전파한다.
- hardlink 원본 교체 중 코어·기존 파일 보존, 미관리 파일이 있는 선택 해제, 링크 생성 실패의 회귀 테스트 3개를 추가했다.
- `docs/GettingStarted.md`와 영어판의 전체 테스트 준비 명령에 `EXTRAS=Gunicorn,Uvicorn`을 지정했다. 일반 core-only editable 계약은 유지한다.
- 한영 Packaging 매뉴얼에 파일별 교체와 미관리 파일 보존, 전체 트리 원자성·실행 중 모듈 재로딩의 비보장 범위를 반영했다.

일반 wheel·제품 API는 변경하지 않았다. 전체 트리 트랜잭션이나 실행 중 import를 잠그는 별도 장치는 추가하지 않았다. 검증은 [작업 기록](../tasks/1793327181554.md)에 정리한다.
