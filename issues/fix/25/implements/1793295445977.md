# 다중 배포 CI와 설치 문서 연결

CI 빌드·게시 준비를 코어와 두 구현체 배포물로 확장했다. `scripts/build_distributions.py`는 버전을 한 번 고정하고 순차 빌드하며, `scripts/prepare_upload.py`는 각 배포물의 이름·버전·빌드 번호·기존 파일 해시를 확인하고 구현체와 코어를 나누어 게시 준비한다. 실제 게시 순서는 구현체 후 코어이다.

깨끗한 환경의 조합별 설치 검사와 릴리즈 준비 단위 테스트를 지원 Python CI에 연결했다. README 세 문서, 설치 매뉴얼과 한국어·영어 Packaging 매뉴얼·목차에 파일 격리, 기존 통합 버전 제거 후 전환, editable 설치 및 빌드 방법을 반영했다.

editable 검증은 코어·각 구현체의 기존 소스 변경 반영과 새 코어 파일 추가 후 재설치까지 확장했다. 해당 최종 확장 검증은 최소 지원 런타임에서 진행한다.
