# CI에서 발견한 어댑터 테스트 계약 정정

`tests/test_adapters.py`의 Uvicorn 출력 실패 테스트에서 `import_module()`로 실제 Server 모듈을 가져온 뒤 `patch.object()`로 모듈의 `startup` 함수를 교체하도록 수정했다. Python 3.9의 문자열 patch 경로가 같은 이름의 공개 Server 클래스로 해석되어 발생하던 `AttributeError`를 제거한다. 출력 실패 시 서버 실행·애플리케이션 시작을 하지 않는 기존 검증은 유지한다.

Gunicorn 수명주기 테스트는 확장 배너가 출력하는 `    - Lifecycle` 줄을 정확히 한 번 검사하도록 변경했다. 일반 Extension에는 더 이상 URL 속성이 없고 `Extension.__str__()`는 클래스 이름을 반환하므로 예전 `Lifecycle: /lifecycle` 기대는 현재 계약과 맞지 않았다. HTTP 요청·업로드·두 작업자의 시작/종료 순서 등 나머지 검증은 유지했다.

제품 코드와 빌드·설치 설정은 변경하지 않았다. 검증 결과는 [CI 실패 재현과 수정 검증](../tasks/1793303776534.md)을 참고한다. 고객 동작 변경이 없어 변경 로그에 별도 항목을 추가하지 않는다.
