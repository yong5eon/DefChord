# 패키지·코드·문서 이름을 DefChord로 전환

`setup.py`의 배포 패키지 식별자를 `DefChord`로 설정하고, 선택형 배포물을 `DefChord-Gunicorn` 및 `DefChord-Uvicorn`으로 구성했다. 패키지 내부 참조, 예제, 테스트, logger 이름, server 식별자, Metrics 이름과 OpenAPI vendor extension 키를 일원화했다.

한국어·영어 README의 소개 문구를 확정한 `Just def. / Define your code. Compose your chord. / You don't need to await this.`로 바꾸고 설치·import 예제를 갱신했다. 상세 매뉴얼과 개발 지침, 빌드·CI 참조도 새 이름으로 동기화했다. `CHANGELOG.md`에 사용자 영향과 런타임 식별자 변경을 기록했다.

검증은 아직 남아 있다. 빌드 및 전체 테스트 실행 결과는 후속 작업 기록에 남긴다.
