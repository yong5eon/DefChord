# 저장소와 원격 이름 변경 및 폴더 이동 차단

- `gh repo rename DefChord --repo yong5eon/DefChord --yes`로 GitHub 이름 변경
- `gh repo view yong5eon/DefChord --json nameWithOwner,url`로 새 이름 조회 성공
- 저장소 루트에서 `git remote set-url origin https://github.com/yong5eon/DefChord.git` 실행
- `git remote -v`로 fetch·push URL 확인, `git ls-remote origin HEAD`로 원격 접근 성공 확인
- 이슈 #28을 새 저장소에서 조회하여 유지 및 `fix` 레이블 확인
- 기존 폴더에서 `fix/28` 브랜치 유지 확인
- 프로젝트 폴더 이름 변경은 `Rename-Item`과 `System.IO.Directory.Move` 모두 접근 거부로 실패

다른 프로젝트 및 VS Code 설정은 변경하지 않았다. 폴더명에 종속된 작업공간 설정이 없었다. 패키지·제품 기능·사용법은 변경하지 않았으므로 상세 매뉴얼은 이번 단계에서 변경하지 않는다. 적용 지침은 공통 이슈 작업 지침, `instructions/DOCS.instructions.md`와 공통 Markdown 지침이다.

당시 프로젝트 폴더 이름 변경은 사용 중인 프로그램 또는 권한 문제로 완료하지 못했다. 프로그램을 임의로 종료하거나 권한을 변경하지 않고 사용자 측에서 폴더를 변경한 뒤 다시 확인하기로 했다.

사용자가 사용 중인 항목을 정리한 뒤 재시도를 요청하여 `fix/28` 브랜치를 확인하고 다시 이름 변경을 시도했으나 동일한 접근 거부로 실패했다. 이후 폴더 이동은 사용자가 직접 완료했으며, 새 경로 확인 결과는 [후속 작업 기록](./1793542490156.md)에 정리했다.
